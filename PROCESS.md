# Process

## Tools

I used ChatGPT to help me understand the downloaded data and write the first
versions of the Python scripts. I ran each version locally, looked at the pictures,
and then asked for changes when something was unclear or did not look right.
ChatGPT also helped me improve the labels and organise the README.

## Kept

I kept the days with no lightning in the picture. At first, the empty days seemed
unimportant, but after seeing the result I realised that they make the lightning
season much easier to notice.

I also kept the logarithmic colour scale. With a normal colour scale, only a few
extreme days were bright and most of the other lightning days were difficult to
see. The logarithmic version showed more variation without removing the extreme
events.

## Rejected

The first result was a rectangular heatmap. It was readable, but it looked more
like a table or a system log than a natural phenomenon. I preferred the circular
version because a year repeats as a cycle.

I also decided not to use 2026 because the data stops in August, which would make
the rest of the year look empty. I considered using a Hong Kong map, but rejected
it because the downloaded data contains only one daily total for the whole
territory and no locations for individual strikes.
